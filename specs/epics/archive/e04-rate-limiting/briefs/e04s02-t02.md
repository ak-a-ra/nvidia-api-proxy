# Task brief — e04s02 / task 2: wire admission gate into `server.js` and test concurrency/queue-full

- **Story:** `e04s02` — Admit and queue work with bounded concurrency
- **Issue:** #15 · **Risk:** P0 · **Security:** high · **Allure severity:** critical
- **Branch:** `feat/e04-admission-control`
- **Task status in ledger:** `failing` — flip to `passing` only when the verify command exits 0

## Objective

1. Wire `createAdmission(config.limits)` into `server.js`:
   - Initialize the admission controller at module scope: `const admission = createAdmission(config.limits);`.
   - In the request handler, gate after the `unconfigured` check and before the upstream request is built.
   - If `admission.acquire()` rejects (e.g. `queue_full`), send 429 with fixed body `{"error":"Too many requests"}` and `Retry-After: 1` (or positive seconds) via `sendJson` (keep-alive drained, no upstream contact).
   - If admitted, ensure the admission slot's `release()` is called on response terminal outcome (or prepare release handling).
2. Update `server.test.js`:
   - Add a stub upstream mode (e.g., `"hold"`, `"controlled"`, or `"block"`) additively, leaving every existing mode untouched.
   - Add black-box tests asserting:
     a. Concurrency ceiling absent, blank, and "0" admits every concurrent request with no wait and no rejection.
     b. Positive ceiling admits up to that many and makes the rest wait.
     c. Full queue answers 429 with `{"error":"Too many requests"}`, positive `Retry-After`, and 0 upstream requests for the rejected one.
   - Tests must drive ordering through the stub's recorded arrivals/promises, never sleeping and hoping.

## Requirements

1. **Gate location in `server.js`:**
   Must be located AFTER:
   - `/health` check
   - `/v1` routing checks
   - `authorized(req)` check
   - `config.unconfigured` check
   And BEFORE:
   - Building headers, URL, and calling `fetch()`.
2. **Rejection contract:**
   - Status: 429
   - Headers: `Retry-After` (e.g. "1" or positive integer string), `Content-Type: application/json; charset=utf-8`
   - Body: exactly `{"error":"Too many requests"}`
   - Drained via `sendJson` so connection stays reusable.
   - Upstream request count for rejected request must be 0.
3. **No leak of limiter internals:**
   - Do NOT export `admission` or `createAdmission` from `server.js`.
4. **Stub upstream additive extension in `server.test.js`:**
   - Leave `silent`, `sse`, `stall`, `slowfinish`, `activelong`, `midabort`, `abortable` untouched.
   - Add additive mode, e.g. `hold`, where upstream accepts request and keeps it open until triggered or closed.
5. **Quality & tests:**
   - Node `--test` tests in `server.test.js` must match names with `concurrency ceiling` and `full queue`.
   - `npm test` passes all tests.
   - `npm run check` passes.
